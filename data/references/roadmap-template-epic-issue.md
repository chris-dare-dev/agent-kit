## Notes on usage

- **Title style:** action verb, no conventional commit prefix. Wrong: `feat: Add X`. Right: `Add X`.
- **`type::epic` label is non-negotiable.** It's how we identify epics in the absence of a native GitLab Epic API.
- **DevStage starts at `Backlog`.** `/issue-advance` moves it forward as the work progresses.
- **Iteration assignment:** if `--iteration <id>` was passed to `/roadmap`, set `iteration_id` on creation via `mcp__GitLab__update_issue` after the issue is created.
- **Child story linking:** after this epic issue is created, capture its iid; pass `--epic-link <iid>` to `/issue-create` for each child story so they get linked via `mcp__GitLab__create_issue_link({link_type: "relates_to"})`.
- **Don't auto-close epic when stories close.** The epic closes when the user runs `/issue-advance` to push it to `Ready for Production` after the milestone-pipeline rectification commit lands.
