## Notes on usage

- **Title style:** action verb, no conventional commit prefix. Wrong: `fix: Update Helm value`. Right: `Update Helm value for X`.
- **Always link to parent epic** via `mcp__GitLab__create_issue_link({source_iid: this_story, target_iid: epic_iid, link_type: "relates_to"})` after creation. The `/issue-create` skill handles this when `--epic-link <iid>` is passed.
- **DevStage starts at `Backlog`.** When the executor (engineer or `/milestone-pipeline`) begins, advance to `In Development` via `/issue-advance`.
- **Iteration assignment:** if `--iteration <id>` was passed to `/roadmap`, set on creation.
- **AC must be Given/When/Then.** If the AC is bullet-shaped instead, the story is at the wrong level (probably a task — fold into a parent story).
- **Cap at 3 AC per story.** > 3 means the story is too big — split via SPIDR (Spike / Path / Interface / Data / Rules).
